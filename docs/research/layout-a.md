## A1：并列主题的重复节奏

观察到的顺序为：近方形视觉封面 → 两段导语 → 三组编号主题 → 现场拼图 → 总结 → 合照 → 结束标记与职责署名 → 品牌照片页尾。

- **封面**：画面约 718×689px；蓝色与暖黄的图形分布在外围，中心白色区域承载两行主文字和胶囊副文字。主副文字是 DOM 文本，外围波形、角标、装饰符号包含独立图片。不能将整个封面判断为单张图片。
- **导语**：真实 `P` 文字，16px、28.8px 行高（1.8 倍）、1px 字间距、两端对齐；外层左右 padding 为 30px。两段文字的 y 值约为 893 和 1008，首段高 86px，段间空白约 29px。
- **编号标题**：三次重复小圆序号与横条标题；标题文字约 18px、加粗，蓝底白字，暖黄形成小范围点缀。标题横条随内容宽度变化，约 335–368px，并非撑满正文。
- **主题内容**：三张主照片约 648×486px，约为内容宽的 90%，保留约 4:3 比例；外层有 10px 白边。照片下面的白色说明块宽约 668px，padding 为 15px，正文 16px/28.8px。照片框底部到说明卡片顶部约 26px。说明高度随字量变化，不强行等高。
- **现场图集**：四张照片分两列排列，单图宽约 304px；左右列间约 19px，每列内照片间约 20px。四张图分别保留不同横竖比例，通过右列上方的短标签和留白错开起点，而非统一裁切。
- **页尾**：结束标记与职责署名为居中 DOM 文字；最底照片包含品牌信息及二维码，整块为图片，不将其中字形视作可编辑文字。

## A2：过程叙事与摄影展示分工

- **主题意象**：浅色底板、绿色主色、暖色辅助，小树等装饰在封面和部分标题旁重复出现。封面主文字有真实 DOM 文本；图形装饰与合照是独立媒体。合照约 538×333px，位于封面下半部，外层为 8px 双线框。
- **导语容器**：上下 1px 细线，绿色线色；容器宽约 617px、padding 为 15px。导语文字 15px/26.25px，少量局部彩色字强调。
- **部分标题**：编号行约 16px、暖色、加粗；下一行主题标题约 18px、绿色、加粗，背景为浅绿横条，padding 为 5px 25px。每个标题上方有小图形呼应主题。

## A3：阶段推进与动感叠图

观察到的顺序为：运动主题封面 → 居中短行开场 → 装饰分隔 → 三个阶段 → 精选瞬间横向图库 → 收束段落 → 装饰分隔 → 结束标记与职责署名。

- **主题色与载体**：浅奶色底板（计算值约 `#FAFDEF`），橙色编号和局部强调；装饰包含媒体图片及 SVG。该正文 DOM 检测到 19 个 `IMG` 和 19 个 `SVG`，不能把 SVG 的视觉形状一律归入位图。封面主副文字仍然存在于 DOM，封面容器约 718×766px，存在变换。
- **开场**：若干居中短行，14px/28px（2 倍），暖色文字；该写法占用较大纵向空间，适合短情绪引导。较长的阶段说明回到深色 15px/24px（1.6 倍）正文，而非全篇保持居中。
- **阶段标题**：橙色小编号块加约 17px 加粗标题，文字下方有 3px 浅暖色短线。三个标题并非全都居中；位置随阶段画面调整。局部次标题约 16px 加粗，并配小三角或细线。
- **错位叠图**：小图组在大小、位置上变化，保持约 20px 圆角；前层图外围可见 5px 与底板同色的边缘，形成清楚分层。某组照片宽约 385px 和 313px；另有约 323px 与 302px 的近方图。观察到容器使用平移变换，截图确认有适度覆盖；不需要把每张照片都做成相同尺寸或相同偏移。
- **主图与细节图交替**：阶段之间有约 625×416px、646×431px 的横向主图，中间穿插叠图与短段。大图给出事件节点，叠图提供多个瞬间；这是对信息节奏的解释，属于推断。
- **横向图库**：外框宽约 624px、1px 橙色线、12px 圆角、14px padding；内部 `DIV` 的 `overflow-x:auto`，可见宽约 594px、`scrollWidth` 为 2376px，包含四张约 594×396px 的图片。截图仅显示首图，下方有操作提示。这证明存在横向溢出的结构；本次未实际滑动，未验证触摸手势、键盘或各图到达状态。
- **收尾**：先用一段正文结束叙事，再以低饱和装饰分隔线进入职责署名。署名为 DOM 文本，字号约 14px、22.4px 行高、6px 字间距；这是该样例的较强装饰性选择，不建议作为所有文章的默认值。

事实证据编号：A3-E1（结构与全页截图），A3-E2（短行开场与正文计算样式），A3-E3（标题样式），A3-E4（叠图边框/圆角/变换），A3-E5（图库 DOM 尺寸），A3-E6（媒体与文本载体）。

可泛化用途：赛事、演出、竞赛等有阶段进展且照片较多的回顾。错位叠图适合人物运动和现场感；需要精读的资料图、含细小文字的截图，应优先完整单列展示。

## 跨样例的选择原则

1. **先选择文章的信息关系，再选择组件。** 并列主题可用重复卡片；过程与作品并重可将说明和图集分工；有明显阶段推进可用编号串联。不要把所有文章都拟合成同一骨架。
2. **图片展示按任务选择。** 单张关键照片用大图；混合横竖的作品用保留比例的组合；多张同类瞬间可考虑横向图库。叠图仅适用于可容忍局部覆盖的画面。
3. **保留文字层。** 样例在装饰繁复的封面上仍使用 DOM 主副文字，正文与署名也保留文本层。插件应把文字内容、装饰媒体和结构容器区分记录。
4. **提取角色而非强制色值。** 三篇分别以蓝黄、绿暖色、橙奶色建立主题。可学习“底色—主色—少量强调色”的分工；正文浅彩字和大字间距必须在目标文章重新核查可读性。
5. **字号与间距是参考范围。** 样例正文约 14–16px，行高约 1.6–1.8；短行开场可到 2。卡片 padding 约 14–15px，普通圆角约 10–12px，叠图约 20px。这是观测集合，不能硬设为全局唯一模板。
6. **脚注职责结构可复用，成品品牌不可自动搬用。** 可保留角色顺序与居中排列的技巧；不保存或复用样例的品牌文字、人员、二维码和图片资产。

# 秀米排版执行入口

制作、编辑和验收以 [PRODUCTION_GUIDE.md](PRODUCTION_GUIDE.md) 为准。先按读者目标选择并列主题、过程叙事、图集或阶段推进，再选择文字、图片与装饰组件；不照抄固定骨架。

## 最短执行路径

1. **硬规定**：先 `xiumi_guide(action="guide", intent="阅读目标、题材、平台与限制")` 读指导，未读时写入类工具直接拒绝、60 分钟内有效；外部样例用 `action=learn`、`url`。
2. 现稿先 `xiumi_articles action=open` → `xiumi_edit action=inspect`，核对 `articleId`、`revision` 与cell列表。改现稿不得以新建代替。
3. 写动作必须 `confirm=true`；多格 `replace_body` 明确 `cellIndexes`，单格用本次检查的 `cellIndex`，未选组件不动。可带 `expectedRevision`；结构变化后重新inspect。
4. `save=false` 仅预览。离开脏稿前显式保存确认，或按用户明确要求 `discard=true`；导航不自动保存。超时/取消先inspect对账，不直接重试。
5. 保存检查 `saved` 和 `saveVerified`；后者需独立页面比较正文模型、样式和图片顺序，不能只看提示、ID或字数。做完 `xiumi_review` 与截图检查；手机、微信端、交互分别实测。
6. 用 `xiumi_guide action=feedback` 反馈已验证效果；自己的作品只算实践，不增加外部样例证据。

## 本地历史实测参考：可选示例

以下保留旧手册已记录的数值和组件ID，供同类任务起步。它们不是通用硬规则；重用前检查当前模板、文字格、效果与目标平台。

- 一组文字参数：小标题18–20px，正文15–16px，结尾强调17–18px，辅助13–14px。另一组已用排版为正文16px、行高1.9、段下距14px；小标题上距18px、下距12px。新稿按密度和目标设备调整，不要求标题固定放大1.25倍。
- 一组配色：主题红 `#C00000`、正文 `#3E3E3E`、注释 `#8A8A8A`、极浅卡片底 `#FFF9F6`。只适用于相符题材，注释也需检查可读性。六篇样例另有蓝、绿、橙与灰黑路线，不设唯一默认主色。
- `85580`：底色标题实例；`86545`：装饰分割线实例；`87993`：底色卡片候选；`88164` / `88133`：关注引导实例，仅在内容确有该用途时采用。
- 组件文字是否可改，要看当前模型、文字格及填充结果并复查。`filled:[]` 不足以证明字在图片里；不能把不可填组件当成功写入。标题优先保留文字层，图形用组件、CSS、SVG或有权使用的媒体；不用手打装饰字符模拟图形。

样例测量和适用条件见 [批次A](research/layout-a.md)、[批次B](research/layout-b.md)。桌面预览数值、SVG内部坐标、编辑器可填性、手机显示和微信兼容是不同的验证对象。
